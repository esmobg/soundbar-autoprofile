# soundbar-autoprofile

**Саундбарът сам сменя звуковия си профил: музика → „Музика“, филм → „Филм“, работа/разговор → „Глас“,
игра → „Игра“.** Започва с Creative Sound Blaster GS5 и е направен така, че да се добавят и други саундбари.

[English](README.md)

Инструментът следи какво се пуска (Spotify, VLC, Netflix, YouTube…), кое приложение е отпред, дали екранът е на
цял екран и дали се ползва микрофонът. После избира профил по твоите правила и го прилага на саундбара през USB.

## Какво работи

| Функция (Sound Blaster GS5) | |
|---|---|
| RGB цвят / яркост за всеки профил | ✅ работи |
| EQ пресет за всеки профил | 🔬 командата още не е разгадана: [помогни с 15 мин запис на USB трафика](docs/CAPTURE_GUIDE.md) |
| SuperWide вкл./изкл. | 🔬 същото |
| Собствени записани команди (`frames:`) | ✅ работи |

| Платформа | Състояние |
|---|---|
| Windows 10/11 | ✅ тествано: медия от всякакви плейъри и браузъри, активно приложение, цял екран, микрофон |
| macOS | ⚠️ нетествано на хардуер: активно приложение, Spotify/Music |
| Linux | ⚠️ нетествано на хардуер: `playerctl`, `xdotool` (X11), `pactl` |
| Android | 🗺️ планирано: приложение през Bluetooth, след като протоколът се разгадае |
| iOS | ❌ невъзможно: iOS не позволява на приложение да следи другите приложения и да управлява саундбара във фонов режим |

Саундбарът трябва да е свързан с **USB-C кабела**. Настройките не могат да се сменят през Bluetooth, оптика или
AUX, но звукът може да идва от всеки вход.

## Инсталация

Трябва ти Python 3.10 или по-нов:

```bash
pipx install git+https://github.com/esmobg/soundbar-autoprofile
```

На Linux копирай `udev/70-gs5-hidraw.rules` в `/etc/udev/rules.d/` (командата е в README.md) и инсталирай
`playerctl` и `xdotool`.

## Бърз старт

```bash
gs5 probe                  # вижда ли се саундбарът?
gs5 detect --watch         # какво се разпознава и кой профил избират правилата
gs5 set movie              # приложи профил веднага
gs5 run                    # автоматична смяна
gs5 autostart install      # стартира при влизане в системата (без администраторски права)
```

**Затвори Creative App** и я махни от автоматичното стартиране, докато това работи. Иначе тя също праща
настройки на саундбара и може да отмени промените.

## Настройки

`gs5 config init` създава конфигурационния файл, `gs5 config path` показва къде е, а `gs5 config check` го
проверява. Профилите казват **какво** да се сложи (eq, superwide, rgb, brightness). Правилата казват **кога**:
проверяват се отгоре надолу и печели първото, което съвпадне. Пример има в README.md.

## Помогни за EQ

Ако имаш GS5 и Windows, следвай [ръководството за запис](docs/CAPTURE_GUIDE.md) (на български е по-долу в
същия файл).
